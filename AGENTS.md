# Instrucciones para agentes

## Continuidad entre chats

- Al comenzar cualquier tarea, lee `CONTEXTO_CODEX.md` si existe.
- Úsalo como resumen orientativo, pero verifica su información contra el código y el estado actual del repositorio.
- Después de cada avance importante y antes de terminar una tarea, actualiza `CONTEXTO_CODEX.md`.
- Mantén el resumen conciso, vigente y sin transcripciones completas, registros extensos, credenciales, tokens ni otros secretos.
- No crees commits ni subas `AGENTS.md` o `CONTEXTO_CODEX.md` salvo que el usuario lo solicite expresamente.
