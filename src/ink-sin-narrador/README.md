# Guion alternativo sin narrador

Esta carpeta es una copia editorial independiente de `src/ink`.

- Mantiene `start.ink`, los nombres de las etiquetas y las elecciones originales.
- No está importada por Vite ni por el juego: sirve para revisar el nuevo ritmo antes de integrarlo.
- Sustituye a `narrator` por tarjetas visuales entre corchetes, SFX, pensamientos y diálogos de personajes.
- Los comandos `# show image`, `# sprite`, `# scene` y los desvíos `->` se conservan para que la futura migración sea segura.

La referencia editorial de los cambios se encuentra en `docs/revision-integral-sin-narrador.md`.
